# Decal Projector

A plugin that builds and projects 3D mesh contour decals onto MeshParts and other basic primitives.

## Building

This plugin requires rokit:
https://github.com/rojo-rbx/rokit

Once you have it installed, open a Git Bash window in vscode and run the following:
```
./wally-install
```

Lastly, press `Ctrl + Shift + B` to build the plugin.
